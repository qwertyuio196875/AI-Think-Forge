# 演示文稿导出说明：截图版 PPT、HTML deck 与 PDF

## 三种产物，一件事

同一份内容可以导出三样东西：HTML deck、截图版 PPT、PDF。三者内容一致，区别在用途。HTML deck 是单文件网页，双击就能全屏放映，也是唯一可以直接改字的一等产物；截图版 PPT 是给人发文件的场合用的；PDF 用于打印和归档。

## 截图版 PPT 是怎么回事

系统先按页面规划渲染出一屏一页的 HTML deck，再用无头浏览器逐页截图，最后把每张图满幅铺进一张幻灯片，装配成 .pptx。视口 1280×720，设备缩放 2 倍，得到 2560×1440 的图，按 13.333×7.5 英寸铺满。

关键一点必须提前说清：**里面的文字在 PowerPoint 里改不了**。每一页是一张整图，不是文字框。要改字就回去改 HTML deck 再重新导出。我们在选择格式的界面上就把这句话写在选项旁边，不留到导出之后才让人发现。

## 页数是硬约束

填完正文后可以指定页数，常用档位 8、12、16、20、30，自定义范围 3 到 60。封面占一页，计入总数。说 16 页就是 16 页，不多不少。章节比页数多时，系统按权重合并相邻章节，合并后的标题写成「第三章与第四章」；页数比章节多时，重点章节拆成几页，用「（一）（二）」区分。

## 字体与失败提示

只用 Windows 自带的中文字体：微软雅黑、宋体、等线。deck 不内联字体文件，这样文件小，但换到没有这些字体的机器上会退化。出图失败时界面会指到具体环节：找不到浏览器、页面渲染超时、图片尺寸不是 2560×1440。不会丢一个 0 字节的 pptx 给你。

## 不支持的事

不套用你提供的 .pptx 模板；不做文字框可编辑的 PPT；不做 Word 转 PDF。
