# Triage Labels

各技能以五个规范的分诊角色来说话。本文件把这些角色映射到本仓库 issue 跟踪器里实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue  |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完整指定，可供离开键盘（AFK）的智能体使用  |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现            |
| `wontfix`                  | `wontfix`            | 不会被处理                     |

当某个技能提到一个角色时（例如“apply the AFK-ready triage label”），就使用本表中对应的标签字符串。

修改右侧一列，让它匹配你实际使用的词汇。
