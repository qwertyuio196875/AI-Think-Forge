# 0001. 拷问工作流采用规则移植，不调用原始技能、不驱动外部 Agent CLI

- 状态：已接受
- 日期：2026-10-19

## 背景

需求文档指定 Matt Pocock 的 `grill-me` 技能为 AI 主题创作的核心设计依据。经核实的事实：

- `grill-me`（`mattpocock/skills`，MIT 许可）本体是 Agent Skills 约定下的提示词规则文件：7 行存根，转调底层 `grilling` 原语（设计树、前沿、轮次格式、事实/决策分离、终止条件）。
- 它只能在 Claude Code / OpenCode 这类 Agent 运行时中生效，没有 Python 接口，不可被应用直接导入调用。

两条集成路线的取舍：
1. **移植**：将 grilling 规则翻译进本应用自研的 Agent 工作流（LangGraph 状态机 + 系统提示词）。
2. **外部驱动**：运行时把 OpenCode CLI 当子进程调起、复用技能原文。

## 决策

采用**规则移植**。把 grilling 的核心机制——设计树/前沿/轮次推进、`❓/➡️` 问答格式、"事实由系统查、决策归用户"、收敛即停——写入本应用拷问节点的提示词与状态机逻辑，并明确标注"基于 Matt Pocock grilling 技能规则的适配版"（MIT 署名保留）。不声称直接调用原始技能。

## 后果

- 应用自包含：无外部 CLI 依赖，会话状态可控、可持久化、可恢复，符合 7 天工期。
- 保真度风险转移给人：移植版行为需定期对照原规则核查；上游技能更新不会自动同步。
- 移植偏离原始规则的任何设计选择（如每轮问题数），须作为显式决策记录，不得静默走样。
