# 0005. 引入最小版 RAG：显式入库、本地索引、可降级检索

- 状态：已接受
- 日期：2026-10-20
- 与 ADR-0002 的关系：取代其「首版不实现 RAG」的结论；其「schema 预留」的做法已被证明有价值（`embeddings` 表恰是本次复用的基础）

## 背景

ADR-0002 的结论建立在两个前提上：知识库为空、期限只有 7 天。前提变了——本次需求明确要求「添加 RAG 库」，语料由我造一批演示数据先用起来。

核实到的代码事实：

- `embeddings` 表**已存在且为空**，结构为 `chunk_id → document_chunks(id)`、`model_name`、`version`、`vector_json`（`backend/app/db/database.py:244-251`），全仓库没有任何写入点；
- 分块链路已存在：`CHUNK_TARGET_CHARS=1200`、`CHUNK_MAX_CHARS=1800`（`backend/app/analysis/chunking.py:16-17`），但代码注释明确写着「这是分析管线的分块，不是 RAG 索引」（`chunking.py:4`、`database.py:209`）；
- 资料侧三表 `sources` / `documents` / `document_chunks` 已成型，`sources.task_id` 可空（`database.py:172`），这意味着「不属于任何分析任务的知识库资料」在现有结构里是允许的；
- 无任何向量依赖、无检索路由、无降级路径。

## 决策

- **知识库资料复用现有 `sources` / `documents` / `document_chunks` 三表**，以 `task_id` 为空表示「知识库资料、不隶属某次资料分析」。不新建平行表族，`embeddings.chunk_id` 因此天然可用。
- **分块复用分析管线的同一套参数**（target 1200 / max 1800，按标题边界切），不做知识库专用分块器。检索命中的位置沿用既有 `locator_json`（format / paragraph / page / slide）。
- **向量存储与检索：SQLite 存块 + 内存 numpy 暴力余弦**，零新依赖、零额外服务。检索层定义 `EmbeddingStore` 抽象，将来换 ANN 索引不动调用方。
- **嵌入模型可插拔**，默认百炼 `text-embedding-v4`（OpenAI 兼容）。未配置或调用失败时**自动降级为关键词/BM25 检索**，功能仍可用但召回变差，界面必须明示当前处于降级；关键词检索也不可用时明示「本次未注入知识库内容」，不得静默按正常流程继续。
- **入库动作：上传即入库**（解析 + 建索引一次完成），任务详情显示「已入库 / 索引中 / 索引失败」。索引失败不阻塞资料本身可读可用，但必须可见——否则用户会把「索引坏了」误判成「库里没有」。
- **介入点两处、均可开关**：拷问阶段的**事实型子环节**（判断当前问题是否需要外部依据，只有这类问题注入检索结果；纯决策型问题不注入），以及填充阶段的正文生成。判定规则写进 `grilling/prompts` 的提示词资产，不交给模型自由心证。
- **引用可见且可撤销**：对话/填充面板以折叠卡片呈现（文件名 · 段落 N · 相关性），默认全选、可逐条取消；被取消的片段不进入本次 prompt。成品附「参考资料」清单，**只列实际使用的来源**。
- **检索参数**：top-k=6，余弦相似度低于 0.3 丢弃，单次注入总长不超过 3000 汉字。
- **演示语料**：约 15 份中文语料（技术文档 / 产品说明 / 调研摘要 / 访谈笔记），主题围绕「AI 辅助写作与文档生产」，放 `fixtures/knowledge/` 并随仓库提交，同时作为 RAG 检索的回归夹具。

## 后果

- 「知识库当前为空」这句在术语表与界面上都不再成立，需一并更新。
- `embeddings` 表的**向量维度**声明尚未与所选模型核对；若与 `text-embedding-v4` 的输出维度不一致，则须新建表或改列（`vector_json` 为文本列，实际上规避了维度耦合，但写入格式必须固定并在读取端校验）。
- `document_chunks` 的注释「这不是 RAG 索引」将不再准确：该表从「分析管线专用」变为「分析与检索共用」。这是一次语义扩大，须在注释与文档中改口，不能装作没发生。
- 检索质量决定这个功能的价值，而检索质量无法靠人工读代码判断，只能靠语料回归测试。**没有 `fixtures/knowledge/` 就没有验收标准**，这批语料不是可选项。
- 中文 BM25 需要分词，而项目当前没有分词依赖。降级路径要么引入轻量分词（如 jieba），要么退化为二元组（bigram）匹配；这条须在实现时定，不能留空。
- RAG 让「模型把自己检索到的内容当用户观点写进正文」成为真实风险。引用可撤销 + 成品附参考资料清单是为此设的两道闸，缺任何一道都会让事后追溯变难。
